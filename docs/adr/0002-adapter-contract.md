# ADR-0002：Adapter 契约以能力声明和统一事件流为核心

- 状态：已接受（阶段 0）
- 日期：2026-08-21

## 决策

每个 Runtime 通过 Adapter 暴露稳定的异步接口。Adapter 必须声明版本、Runtime 兼容范围、支持能力和权限需求。核心只依赖统一的任务请求、事件、健康检查和会话引用，不读取具体 Runtime 的内部配置或输出格式。

不支持的能力必须显式返回 `unsupported`；不能为了统一 API 而模拟不存在的 session 恢复、取消或事件。

## 事件约束

事件包含 `runId`、序号、时间、类型和安全处理后的 payload。Adapter 可以保留原始事件引用，但不能将凭证或未脱敏敏感信息写入统一事件。

## 后果

新增 Runtime 的主要工作落在 Adapter 包和兼容测试中；核心不因单一 Runtime 的 CLI 参数变化而频繁修改。不同 Runtime 的能力差异会暴露给调用方，这是可解释性优先于伪兼容性的取舍。
